# 迭代 7：结果优先，减少说明性界面

日期：2026-09-23。范围：已保存的 Eino 执行结果。工作台、嵌入组件、离线 HTML 同步收敛；
不新增实时、流式、业务执行、发布或部署能力。

## 展示取舍

原则是让真实内容承担解释，而不是在每块内容旁再放一段产品说明。删除的是展示噪声，
不是原始字段；完整记录、来源和诊断仍可按需查看。沿用现有冷蓝、纸白和字体，
通过间距、正文排版及折叠层级突出结果，没有另起一套视觉风格。

| 内容 | 展示方式 | 原因 |
| --- | --- | --- |
| Agent / Graph / Workflow | 保留三个入口；导入时自动识别 | 业务语义不同，不要求用户理解底层适配器 |
| 输入与最终回答/输出 | 直接展示；最终结果优先 | 是打开记录首先要回答的问题 |
| 成功、失败、取消、中断、未知、仅声明 | 保留短状态 | 不把记录缺失、声明或计划误当成功执行 |
| 完整采集 | 收进运行信息 | 正常状态无需重复占据首屏 |
| 部分采集、脱敏、截断、省略、未记录 | 在相应结果保留短状态 | 会影响读者对内容完整性的判断，不能隐藏 |
| 运行耗时 | 有可靠记录时展示，真实零值保留 | 不从缺失时间推导零；观察跨度不冒充执行时长 |
| 起止时间、时间来源、运行 ID | 运行信息内展开 | 有排障价值，但不应压过结果正文 |
| 导入文件名 | 保留，长名称可换行 | 确认正在阅读哪份记录；内置示例不重复显示已选名称 |
| 字符串正文 | 可换行的普通文本；长文可展开、复制 | 不强迫用户通过 JSON 转义阅读回答 |
| 对象与数组 | 保留完整键、值和嵌套的格式化 JSON | 不猜测天气等业务字段，不擅自挑选所谓核心字段 |
| 空字符串、null、0、false | 独立保留；易混淆的字符串标明文本类型 | 空值和类型本身也是结果，不用输入替代空输出 |
| 工具请求 | 按真实消息结构展示名称和参数 | 空 content 不代表没有工具调用意图；计划仍不等于执行 |
| 步骤名、组件类型、状态 | 简短名称与类型；保留不确定状态 | 去掉可推导的协议前缀，不改真实名称或执行事实 |
| 节点 ID、完整路径、回调和关联字段 | 来源、Raw 或技术详情中保留 | 用于精确身份与定位，不当作默认标题堆叠 |
| 调用目录、面包屑、步骤数量 | 简短导航；切换不强制打开检索列表 | 保持当前阅读位置，不把导航变成说明区 |
| 当前调用输入、返回、错误 | 子调用单独展示；顶层不复制整次结果 | 局部返回不能替代根最终结果，也不能由最后子步骤猜出 |
| 跨范围连接 | 有连接时显示数量 | 保留局部路径上下文；不补造连接，不显示全零噪声 |
| 步骤错误与业务输出 | 分区；只对同源同文错误去重 | 错误不能看起来像普通返回；同一事件的独立业务返回也不能丢 |
| 整体成功但存在局部错误 | 保留可展开的错误计数和处理状态 | 全局成功不抹去局部失败；默认不重复展开整段错误 |
| 来源信封及诊断 | 来源按钮折叠分组，诊断按需打开 | 内容可追溯，但协议字段不必常驻主阅读区 |
| Raw 原始记录 | 默认只读；明确点击“编辑副本”后编辑 | 防止阅读时误改；跳来源时保存草稿，可恢复 |
| 产品介绍、协议横条、常驻快捷键说明、重复 summary | 有记录时不展示 | 不提供新的运行事实；将首屏空间让给结果 |
| 空目录、重复最终结果、无意义序号、重复“耗时未记录” | 不展示 | 避免空操作和暗示并不存在的执行顺序或计时事实 |

## 同步修复的技术问题

- 内容选择依据真实信封类型和消息角色，不依赖翻译后的标签或天气字段。
- Tool 消息的字符串 `"null"`、`"0"`、`"false"` 不再沿用投影中的解析值；真实组件 null 仍为 null。
- 一个组件正文因大小限制未录下，不能遮住同一步骤另一个真实来源已经记录的工具返回。
- 错误分类同时核对来源角色与实际错误值，或 Workflow 的完整路径与执行 outcome；
  同一 AgentEvent 同时包含 error 和 Tool 消息时，保留独立业务内容。
- 来源跳转依次打开外层到内层折叠区；Raw 编辑草稿与已接受记录分离，跳转后仍可恢复草稿。
- 节点耗时按完整路径匹配；缺少有效起止边界不编造时长，真实 0 ms 不丢失。
- 私有展示辅助模块进入站点版本化构建；没有新增公共 API 或运行依赖。

## 保留的限制

- 严格矩阵仍有四项已知限制：两份旧 Graph 记录没有 I/O 正文，一份超限正文安全省略，
  一份并发 Agent 的 name-only 事件无法确认调用身份。没有靠界面补造未采集内容。
- 工作台“未归属”调用入口按未归属步骤计数，嵌入版也允许只有未归属证据的范围。
  生命周期、定义和根调用等非步骤证据仍可从完整 Raw、来源或未归属证据检索访问。
- 不声称覆盖 Eino 的全部 Agent 语义；直接转交、中断后恢复、多运行比较仍需单独约定。
- `eino-workflow-dag` 未修改，工作区干净，仍为已发布版本对应的 `286f3d7`。

下一步优先用匿名化真实项目记录验证阅读成本；不为了迭代次数增加新面板和说明文案。
