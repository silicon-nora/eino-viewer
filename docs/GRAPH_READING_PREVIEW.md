# Graph 工作台体验试版

## 范围

参考已验收 Agent 的精简原则，本轮只优化工作台 Graph；Agent、Workflow、完整嵌入组件与离线版保持原样。Graph 方案仍待 Owner 确认，确认后再考虑抽取共享展示，不将未定稿方案当作三入口标准。

公开 API、Recorder、记录格式、原始数据、执行关系、访问顺序及上游仓库不改。不增加实时、流式、执行或发布功能。

## 阅读设计

- 执行路径作为主区，步骤列表用于搜索、键盘选择和重复访问定位，右侧直接读输入／输出。
- 正常运行的整次结果收为可展开摘要条，保留耗时；失败／取消／中断自动展开原始原因与有唯一关联的定位操作。详情仍默认首项，不用中间节点的输出代替根结果。
- 移除 Graph 的原始记录编辑、技术详情、证据目录、重复详情按钮、主题／方向设置及重复成功标签。只隐藏已确认成功，异常、未完成、仅定义、采集缺失／脱敏／截断继续明确表达。
- 保留图的缩放、适应画布和主动折叠。绘图保护仍按当前完整范围判断，不用搜索结果绕过 500 节点门限。
- 保留每次真实访问的身份与原值，例如 `evaluate` 的第 1／2／3 次。不合并同名调用，不用 Workflow 依赖排序改写 Graph。
- 只有一个完整平层范围时不重复展示调用目录；多个范围仍保留必要的选择与返回导航。
- 详情先输入后输出，原文完整显示；没有 I/O 复制和关闭按钮，保留 Escape 返回触发项。主结果正文的原值复制保留。

视觉沿用已认可的浅色、蓝色和本地字体。宽屏为紧凑步骤栏、主要路径区与 320px 详情栏；中等宽度详情下移；手机按路径、步骤、详情排列。图高随范围规模增加并封顶，不改变节点和连线数据。

## 验证记录

2026-09-29，同一冻结产品代码分两批完成完整范围回归：

- Chromium **254 / 254**；Firefox **173 / 173**、WebKit **173 / 173**，合计 **600 / 600**。这是分批结果，不是单次进程运行；最终两批均无失败、跳过或重试。
- **21 个 JS 产品测试入口、语法、类型检查通过**。32 场景严格检查为 `passed-with-limitations`，四项既有限制不变：Graph step-limit 和 cancelled 两类记录缺少 I/O、超限正文主动省略、并行子 Agent 事件无法唯一归属。
- 当前 254 个独立案例：P0 173、P1 71、P2 10、P3 0。本轮仅新增两项（P0、P1 各一）；四视口是 P1 内部检查，不另计案例。没有删除或降级旧用例，也没有扩张 Recorder 数据矩阵。
- 原始记录、正文、来源关联、循环访问身份、500／501 门限、隐藏挂载／销毁和跨入口隔离继续校验。被移除控件的测试改为当前可见步骤操作；原始记录编辑仍由保留该能力的 Workflow 入口验证。
- 初轮 Chromium 248 / 254，暴露旧控件断言、失败无输出的测试假设、分页后目标不在当前页及正文来源标记问题；分别迁移交互、保留真实缺失语义与选择关联、补回被动来源标记后完成上述复验。没有通过弱化原始事实断言消除失败。

### 保留边界

Graph 仍待 Owner 的视觉和交互验收。嵌入／离线 Graph 尚未同步，Workflow 没有调整；路径沿用原始执行关系，不把父子回调关系改写成顺序或依赖关系。没有重新采集 Recorder、调用付费模型、配置远程仓库或发布；上游仓库保持干净。

本轮为开发代理自测，不冒充陌生用户研究。前端设计技能用于落实既有视觉方向与信息减法，浏览器测试技能用于核对实际路径、正文、焦点和响应式行为。
