# 迭代 6：复杂调用的局部结果阅读

日期：2026-09-23。范围：已保存 Eino 运行记录的局部阅读，不增加流式、实时、业务执行或发布。

## 本轮交付

- 工作台、嵌入组件与离线 HTML 的目录/面包屑联动局部路径、输入、返回、错误和 Raw 证据。
- 整次最终结果始终独立。跳转最终结果不清空局部范围；主动查看范围外证据时返回全范围。
- 局部图只使用原执行节点和范围内原边。跨范围连线单独计数，不补造连接、开始/结束执行
  或新的运行状态。原记录、标准投影、节点 ID、循环访问身份及原始信封索引不变。
- 调用返回必须匹配真实边界、完整地址及回调身份；不能拿最后一个子步骤、子 Agent
  回答或全局最终结果代替。缺失、空串、null、0、脱敏、截断和省略继续分开表示。
- 子调用失败与调用方处理错误分开。调用方的边界错误有专用标签，不将其恢复状态套给子调用。
- 声明 Workflow 读取自身子树，点击补回完整原路径；声明 Graph 保留有环结构。不将声明
  变成真实执行；未确认归属的记录也不被当作一次调用。空范围有明确空状态。
- Agent 轨迹/完成态重放仍是整次运行视图。切换轨迹返回全部步骤，切换调用目录返回路径并暂停重放。

界面沿用原有冷蓝、纸白和字体，以面包屑和“当前调用”结果区表达层级，没有新一级板块。
全局结果折叠状态、Raw 草稿、语言切换及无效导入的保真行为继续回归。

## 保留边界

- 仍有四项已知限制：两份旧 Graph 样例没有 I/O 正文，一份超限正文被安全省略，一份并发
  Agent 的 name-only 事件归属未确认。局部阅读不能恢复未录下的数据。
- 没有边界记录就没有可确认的局部调用结果。父返回不保证每个下级步骤成功。
- 不扩展中断后恢复、直接 Agent 转交、多运行对比、在线服务或公共重放控制 API。
- 没有新增公共 API 或运行依赖。局部模型和嵌入图使本地 SDK 压缩包约从 158.6 KiB 增至
  169.7 KiB，体积门禁有界调整到 175 KiB；离线 HTML、站点和样例仍不进入 SDK 包。
- `eino-workflow-dag` 未修改，工作区干净，仍为 1.3.1 工作树（`286f3d7`）；版本、发布与部署均未执行。
