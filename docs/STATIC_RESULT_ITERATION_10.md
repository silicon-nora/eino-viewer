# 迭代 10：重复调用与长错误的静态阅读

日期：2026-09-23。仍只读取已保存的非流式结果；不增加实时、执行器、公共接口或发布步骤。

## 分析、验证与判断

人工打开上一轮的真实多轮 Graph，确认三个 `evaluate` 在列表和图中同名，必须逐个打开
才能知道是哪次调用。身份与 I/O 没串，但阅读上缺少必要的区分。

另用合成的 300 多行错误压测：工作台已有折叠，嵌入式与离线版的运行/局部错误却直接
铺全文，没有复制入口。长文本预览还有按 UTF-16 截断 emoji 的缺陷，会留下孤立代理字符。

这三项均属于静态阅读质量问题，因此直接修复。沿用既有视觉布局，只补事实性标签与
现有的全文展开控件；不增加说明面板，不把本轮 UI 压测称为新增真实 Recorder 场景。

## 实现

### 1. 有证据的重复调用次序

对同一来源、同一父调用中的重复串行 callback 调用，在列表、详情、图中及键盘描述中
显示“第 1 次 / 第 2 次”等标签；英文为 `Call 1 / Call 2`。工作台错误标题和来源所属
步骤也使用相同标签。

编号由整次运行预先生成，不跟随搜索、失败过滤、分页或局部图重新计数。只接受显式且
唯一的 invocation ID、匹配的完整地址/路径/组件/实体/运行身份，以及完整开始和终止
边界。相邻调用必须不重叠；父调用边界须包含子调用。身份冲突或残缺的同源组不会把
剩余记录重新编号为“第 1 次”。不借业务字段 `round`、节点数组次序或相同时间戳猜次序。

并行调用、缺失边界、同名不同路径或不同父调用均不强行编号。Agent 工具调用仍使用
既有身份语义，不能把工具计划或名称相同当作完整 Graph callback。本轮不宣称已消除
所有 Agent 同名调用的阅读成本。

以上是私有展示映射：不改原始名称、标准投影、运行状态、因果边、输入输出或导出内容。

### 2. 长错误统一使用正文阅读控件

嵌入式和离线版的运行错误、局部错误、调用方错误及步骤补充错误统一支持预览、默认
折叠、键盘展开、全文复制与原始来源。恢复/调用方标签独立于错误正文，复制不混入
标签或省略号；整体成功、局部失败、调用方已处理仍分别表达。错误不侵占业务输出。

### 3. 预览不切断 emoji

共享预览按 Unicode 码点截断，不拆合法代理对；至多读取预览限额加一个码点，不把巨型
字符串整体转成数组。工作台正文、摘要和嵌入式预览共用此规则。展开、复制、Raw 和导出
保留原文。该保证是码点安全，不宣称实现所有组合字符/家庭 emoji 的字素簇分段。
